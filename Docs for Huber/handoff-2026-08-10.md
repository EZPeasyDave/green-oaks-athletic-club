## Facts that cost time today

All captured in project memory (`reference_stripe_api.md`), but the short version:

- Stripe has **no API tiers** — nothing to upgrade, restricted keys are free.
- Custom field **answers live on the Checkout Session**, not the charge. That is
  why the dashboard's Payments CSV omits them.
- `list()` returns **full** session objects — byte-identical to `retrieve()`.
  Confirmed directly; do not add per-session retrieval "just in case."
- **`StripeObject` has no `.get()`** (stripe-python v15). Use `.to_dict()`.
- **Abandoned carts are normal.** 99 sessions → 48 real signups. An unpaid
  session with no custom fields is not a bug. Only a *paid* one is.
